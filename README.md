# Bibliosfera 📚

> **Bibliosfera** — Gestor minimalista de lecturas y biblioteca digital con vistas 3D, lomos orgánicos e integración con dispositivos eReader / USB.
> 
> **Versión:** v1.0  
> **Desarrollada por:** Óliver Rivero

---

### ✨ Características destacadas
- **Mis lecturas:** Cuaderno interactivo con métricas anuales, mensuales y de ritmo lector, valoración por estrellas, notas y sinopsis.
- **Biblioteca digital:** Colección de e-books (EPUB, PDF...) con visualización en estantería flotante y vista de tarjetas.
- **Vista de lomos:** Representación realista y orgánica de los libros en la estantería, con colores armonizados con la portada, grosores proporcionales y tipografía editorial.
- **Transferencia a eReader / USB:** Detección automática de lectores de libros electrónicos y memorias USB conectadas por cable para transferir archivos mediante arrastrar y soltar (*drag & drop*).
- **Ajustes y portabilidad total:** Exportación e importación en CSV, Markdown, páginas HTML independientes y JSON sin depender de la nube.
- **Modo Claro y Oscuro:** Interfaz refinada monocroma y paleta editorial inspirada en diseño nórdico.

```bash

```

### Development

```bash
$ npm run dev
```

### Build

```bash
# For windows
$ npm run build:win

$ npm run build:mac
```
